# هايبر الشهير — تصنيف الأقسام والمنتجات

مشروع مستقل يقرأ منتجات EasyOrders عبر اتصال GitHub الحالي، **ولا يغير أي بيانات في المتجر أو فيد Meta**.

## ما الذي يفعله؟

- يتعرف على الأقسام بالمعرّف الحقيقي `categories[].id`، ويحتفظ بالاسم `name` والرابط المختصر `slug` (مثل `fridge` و`SPICES`).
- يدعم ظهور نفس المنتج ضمن أكثر من قسم، دون تكراره في إجمالي المنتجات الفريدة.
- يحدد حالة الظهور لكل منتج من قيم `hidden`, `is_hidden`, `active`, `visible`.
- ينتج ملفات جرد شاملة للتشخيص، وملفات أخرى `magazine_ready` لا تحتوي إطلاقًا على أي منتج مخفي أو غير مؤكد.
- يستبعد من المجلة: المخفي، غير المؤكد، ناقص المخزون المتتبع (رصيد 1 أو أقل)، ناقص الصورة أو السعر أو الاسم أو القسم.
- إذا كان `track_stock = false` فلا نستبعد المنتج تلقائيًا عند ظهور `quantity = 0`؛ فهذا لا يدل على نفاد المخزون.
- **الاسم والسعر والصورة تأتي من EasyOrders فقط**، وليست بيانات مولدة.

## التشغيل

من **Actions → Grouped EasyOrders Catalog Export** في GitHub، شغّل `Run workflow` بعد دمج هذا الفرع في `main`. بعد ذلك تتكرر المهمة يوميًا وتنتج Artifact اسمه `grouped-catalog-magazine-safe`.

مفتاح EasyOrders محفوظ كـGitHub Secret باسم `EASYORDERS_API_KEY` في المستودع الحالي ولا ننسخه في الكود.

## الملفات

- `summary.json`: إجمالي عدد المنتجات، الأقسام، وعدد المؤهل للمجلة.
- `categories.csv` و`categories.json`: أسماء الأقسام والـslug والمعرف وعدد المنتجات الظاهرة والمخفية *ضمن استجابة API*.
- `magazine_ready/<slug>-<id>.csv/json`: منتجات كل قسم المؤهلة فقط (الاسم، السعر، الصورة، المعرف).
- عند التشغيل محليًا تتولد كذلك ملفات `audit_all/` و`all_products.csv/json` للمراجعة، وتتضمن أسباب استبعاد المخفي؛ **لا ترفعها إلى GitHub Pages أو مواقع عامة**.

## حدود الدقة

إذا كان EasyOrders API لا يُرجع المنتجات المخفية أصلًا، فقد يكون عدد المخفي في تقريرنا صفرًا رغم وجود منتجات مخفية في المتجر. لذا `hidden` يعني **مخفي ضمن المنتجات التي أعادها API فقط**، وليس جردًا قطعيًا لكل المخفي. كذلك المنتجات التي ليس لها معلومات قسم تُستبعد من ملفات المجلة حتى تُراجع.

**الأسعار لقطة بتاريخ استخراج الملف وليست أسعارًا حية بعد النشر.** لا تنشر صفحات المجلة القديمة دون تحديث.

المستودع الحالي عام؛ لهذا ترفع المهمة ملفات المؤهل للمجلة فقط، وليس قائمة أسماء المنتجات المخفية.
