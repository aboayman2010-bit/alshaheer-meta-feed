# مجلة عروض هايبر الشهير — إصدار تجريبي تلقائي

**الغرض:** إنشاء مجلة دعائية بصور جاهزة للنشر يدويًا في جروبات أسيوط، وليست متجرًا ثانيًا ولا نشرًا تلقائيًا في الجروبات.

## التقسيم: 8 صفحات / 36 منتجًا
1. غلاف المجلة + الدعوة إلى تحميل التطبيق
2. وفر أكثر (6 منتجات)
3. وفر أكثر (6 منتجات أخرى)
4. منتجات الثلاجة والألبان (6)
5. السلع الأساسية (6)
6. المشروبات والحلويات (6)
7. المجمدات والمتنوع (6)
8. الخاتمة + بيانات الهايبر + التطبيق والموقع

## التنفيذ
- المصدر: Easy Orders API المتصل بالمشروع (بنفس GitHub Secret: `EASYORDERS_API_KEY`).
- سكريبت مستقل: `magazine/build_magazine.py` (لا يُعدل فيد ميتا).
- ينتج `page-01.jpg` … `page-08.jpg`، و`alshaheer-magazine.pdf`، و`post.txt` و`report.json`.
- تحميل الناتج من **Actions → Build Weekly Magazine → Artifacts → alshaheer-magazine**.
- تشغيل يدوي أو أسبوعي؛ مع مراجعة الصور والأسعار قبل نشرها في الجروبات.
- الصور والأسعار من Easy Orders فقط؛ لا تُخترع أسماء أو صور أو أسعار، ولا نعرض سعرًا قديمًا على أنه خصم تلقائيًا.
- لا يظهر المنتج إذا كان مخفيًا أو بلا سعر صالح أو صورة قابلة للاستخدام. عند قلة المنتجات المناسبة يتم رفض إنشاء مجلة ناقصة، ولا يُنشر إصدار مضلل.
- الصور النهائية 1080×1350 مناسبة لمنشورات فيسبوك؛ الخلفيات هادئة، والأسماء والأسعار واضحة.
- لا تغيير أو حذف للمتجر الأساسي أو كتالوج ميتا.

**حالة المشروع:** نموذج قابل للاختبار. راجع تقرير جودة البيانات وعدد المنتجات المؤهلة من أول تشغيل حقيقي، ثم اعتمد النشر الأسبوعي.

**الروابط:** https://alshaheer.myeasyorders.com/ — https://play.google.com/store/apps/details?id=com.store.alshaheer

**مهم:** لا تضع مفاتيح API أو كلمات المرور في الملفات أو الصور أو سجل GitHub. المفتاح السابق الذي ظهر في المحادثة يحتاج تدويرًا إن لم يُستبدل بعد.
